# AI Research Assistant Chrome Extension

Chrome extension that augments web research with AI summarisation and note-taking. Highlights key passages on any webpage, generates one-paragraph summaries, extracts structured data like dates, names, and prices, and saves research notes to an Obsidian vault or Google Docs via webhook. Features side-panel research workspace, citation formatting in APA, MLA, and Chicago, and a semantic search across all saved notes. Ideal for students, analysts, and journalists doing deep background research across dozens of tabs.

## Installation

### Chrome
1. Download and extract the ZIP
2. Go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extracted folder

### Firefox
1. Download the Firefox version
2. Go to `about:debugging`
3. Click "Load Temporary Add-on"
